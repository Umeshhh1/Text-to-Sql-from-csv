This project is a Streamlit-based application that allows users to upload a CSV file and ask questions in normal, everyday English. The application automatically converts the uploaded CSV into a SQLite database, understands the user’s natural language query, generates the corresponding SQL query using a Large Language Model, executes it on the database, and displays the results in a tabular format. The goal of this project is to make data querying easy for non-technical users without requiring any SQL knowledge.

The project is built using Python, Streamlit for the user interface, SQLite for database storage, Pandas for data handling, and Groq’s LLaMA 3.1 model for natural language to SQL conversion. API keys are securely managed using Streamlit’s secrets.toml file and excluded from version control using .gitignore. This project demonstrates practical usage of Generative AI in data analytics and showcases real-world handling of user queries, SQL generation, and execution.
